## 🚌 Featured project: Traxis

**A public transport coordination application.**

- **Problem:** private shuttle services often rely on fragmented phone calls and manual processes to book and coordinate passengers.
- **Solution:** a centralized platform to book transport, view available seats, receive booking information, track transportation and manage passenger information.
- **Technology:** Vue.js, FastAPI, REST APIs, database.

**My role: Frontend Developer (final year project).** I built the web-based admin dashboard using Vue, TypeScript, Vite, Vue Router and ApexCharts:

- Admin authentication and protected routing
- Backend API integration with token-based authentication
- Dashboard analytics, summary cards, and revenue and profit charts
- User management and administration
- Booking and parcel management
- Companies, routes, drivers and vehicle management
- Reusable layouts, modals and UI components

The result is a central control panel for monitoring system performance and managing users, bookings, parcels and transport operations.
